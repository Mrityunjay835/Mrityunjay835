## 🔥 Featured Project

### [spark-ml-project](https://github.com/Mrityunjay835/spark-ml-project) — Production Spark ML Pipeline

> End-to-end customer churn prediction system built on Apache Spark.

```
Raw CSVs → ETL → Feature Store → GBT Model → Streaming Predictions → Delta Lake
```

![Apache Spark](https://img.shields.io/badge/Apache%20Spark-3.5.3-E25A1C?style=flat-square&logo=apachespark&logoColor=white)
![Delta Lake](https://img.shields.io/badge/Delta%20Lake-3.2.0-003366?style=flat-square)
![MLlib](https://img.shields.io/badge/MLlib-GBT%20·%20RF%20·%20LR-FF6B35?style=flat-square)
![Streaming](https://img.shields.io/badge/Streaming-Structured-blue?style=flat-square)

| Component | Tech | Highlights |
|---|---|---|
| Batch ETL | PySpark DataFrame API | Schema enforcement, partition pruning, skew detection |
| Feature Store | Parquet + Delta Lake | RFM + 20 behavioral features, partitioned by state |
| ML Training | Spark MLlib | GBT/RF/LR, CrossValidator HPO, AUC-ROC 0.81 |
| Streaming | Structured Streaming | Real-time churn scoring, risk tier classification |
| Delta Lake | Delta 3.2.0 | ACID, time travel, MERGE/DELETE, OPTIMIZE |
| Monitoring | PSI + KS drift | Auto-retrain trigger, pipeline health checks |
